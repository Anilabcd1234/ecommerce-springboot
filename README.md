# E-Commerce Spring Boot

A full-stack E-Commerce application with Spring Boot backend and HTML/JS frontend.

## Features
- Product Cart
- Order Management 
- Payment Methods
- H2 Database

## How to Run
1. Clone repo
2. Run `Ecommerce1Application.java`
3. Open http://localhost:8080

## Tech Stack
Spring Boot, JPA, H2, HTML, JavaScript
